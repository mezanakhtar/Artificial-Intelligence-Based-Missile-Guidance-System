# Artificial Intelligence-Based Missile Guidance System

## 📌 Overview
This project presents an AI-powered autonomous missile guidance prototype using Computer Vision and Embedded Systems. The system uses YOLO-based object detection integrated with Raspberry Pi to detect, track, and align targets in real time.

The project combines:
- Deep Learning
- Computer Vision
- PID Control
- Kalman Filtering
- Embedded AI

---

## 🚀 Features
- Real-time object detection using YOLO
- Autonomous target tracking
- Servo motor-based launcher alignment
- Kalman Filter for smooth tracking
- PID controller for precision control
- Relay-based launch simulation

## ⚙️ Working Flow
1. Capture video input
2. Detect target using YOLO
3. Track target using Kalman Filter
4. Calculate alignment using PID controller
5. Adjust servo motors
6. Simulate missile launch

---

## 📊 Results
- Detection Accuracy: ~80–90%
- Tracking Latency: < 200 ms
- Servo Accuracy: ±2° to ±4°
